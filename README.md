how to start using this server

    1. npm i ###install all the dependensies

    2.npm run docker:up ## configure docker

    only run when step 2 is complete do after the docker is up and running...
    3. npm run seed:admin ### watch for the login credentials

    4. npm run seed:student ## this command SEEDS the student to the DB

    5 test the route using bruno

    6 when hitting the student route make sure to login or get token using teacher login && copy the Token 

    7 select the Bearer Token opt in Auth tab in bruno paste the copied token here then hit the route happy testing...
